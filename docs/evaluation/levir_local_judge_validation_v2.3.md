# LEVIR-CC Caption语义判定器v2.3验证说明

## 验证对象

- 实现版本：`levir-local-text-judge-v2.3-hybrid`；
- 判定配置：`local_text_judge_priority_v1.3`；
- 主模型仍只生成自由文本Caption，不进行第二次图像推理；
- 评审器只读取Caption，不读取图像和`metadata.changeflag`作出语义判断。

## 人工语义有效性

独立保留集由两名标注者分别标注并完成分歧裁决。200条中有191条获得`0/1`金标准，9条
保留为`U`并排除在二分类指标分母之外。

| 指标 | 结果 |
| --- | ---: |
| 样本数 | 191 |
| Accuracy | 86.39% |
| Balanced Accuracy | 85.41% |
| Change Precision | 83.33% |
| Change Recall | 94.34% |
| Change F1 | 88.50% |
| TP / TN / FP / FN | 100 / 65 / 20 / 6 |

旧上下文解析器在相同样本上的Accuracy为55.50%，v2.3提高30.89个百分点。人工语义金标准
直接衡量评审器是否正确理解Caption，不以图片真实标签代替评审器有效性验证。

## 完整任务结果

使用同一v2.3实现重新判定1,333条LEVIR-CC回放模型输出：

| 指标 | 结果 |
| --- | ---: |
| Accuracy | 89.65% |
| Balanced Accuracy | 89.65% |
| Change Precision | 97.49% |
| Change Recall | 81.41% |
| Change F1 | 88.73% |
| TP / TN / FP / FN | 543 / 652 / 14 / 124 |

该结果衡量主模型描述与图像级`changeflag`的一致性，不等同于评审器自身准确率。

## 已解决的严格判定问题

最初的固定无变化表达白名单只能识别少量完全一致句子，容易把合理的自由描述全部判为变化。
v2.3改为三级级联：高置信无变化、高置信永久目标变化、高置信非目标差异，无法确定的文本才交给
本地Qwen3-1.7B。规则同时处理否定、复合句及`appear/appearance`词义歧义。因此主模型不需要
额外学习0/1格式，也不会增加主模型的图像推理次数。

## 使用限制

- 该判定器输出的是Caption语义标签，不是图像级事实正确率；
- 14条假阳性需要原始A/B图像才能区分模型幻觉和数据集标签问题；
- 本地小模型只处理规则无法确定的Caption，其离线耗时必须与主模型推理耗时分开报告；
- 任务指标属于内部评测口径，不称为LEVIR-CC官方二分类指标。

## 可追溯性与数据边界

运行清单保留在仓库外，避免泄漏个人路径、扩大仓库体积或混淆可复现代码与实验产物。
